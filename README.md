# disorder map

A dark, minimal public map of topics, articles and books. Folders are white; publication nodes are gold; connections are grey. Click a folder to expand it and a publication to open its details on the right.

The public catalog (`catalog.json`) is generated by the private repository **disorder-private**. PDF originals are **not** part of this public repository unless their SHA-256 has been explicitly approved for public redistribution.

## GitHub Pages

Repository **disorder** must be **Public**.

In `Settings → Pages`, choose `Deploy from a branch`, `main`, `/(root)`, then Save.

To update, commit new books/articles to **disorder-private**, not here. Its GitHub Actions workflow publishes an updated catalog here.
