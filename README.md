# Атлас статей — готовый пример для GitHub Pages

Это демонстрационный статический сайт с иерархическим графом папок и статей. Можно использовать без Obsidian и Quartz.

## Опубликовать на GitHub Pages

1. Распакуйте ZIP на компьютере.
2. В публичном репозитории GitHub откройте `Add file → Upload files`.
3. Перетащите **содержимое папки** `articles-graph-starter` (а не ZIP и не родительскую папку) в окно загрузки. Должны появиться `index.html`, `style.css`, `graph.js`, `data/articles.json`, папка `papers/`.
4. Подтвердите загрузку через `Commit changes` (или `Propose changes` и затем объедините pull request, если GitHub предлагает такой путь).
5. В репозитории откройте `Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save`.
6. GitHub отобразит публичный URL вида `https://USERNAME.github.io/articles-graph/`.

> Не пытайтесь открыть `index.html` двойным нажатием как локальный файл: для чтения JSON нужен веб-сервер. Через GitHub Pages всё работает.

## Поменять демо-статьи на свои

1. Загрузите свои PDF-файлы в папку `papers/` (можно создать подпапки).
2. Откройте `data/articles.json` на GitHub и нажмите значок карандаша (`Edit`).
3. Замените демонстрационные записи на свои. Каждая **папка** — объект с `type: "folder"` и массивом `children`. Каждая **статья** — объект с `type: "article"`, `abstract` и относительным `pdf`.

Образец статьи (внутри массива `children`):

```json
{
  "id": "unique-article-id",
  "name": "Название статьи",
  "type": "article",
  "abstract": "Краткий пересказ abstract на русском языке.",
  "pdf": "papers/AI/my-article.pdf"
}
```

Важно:
- Значения `id` должны быть уникальными.
- `pdf` — путь относительно корня сайта; имена и регистр букв должны в точности совпадать.
- Закрывающая запятая после последней записи в JSON **не нужна**.
- Структура папок в графе определяется `children` файла JSON. **Автоматическое обнаружение PDF в GitHub пока не включено** — это следующий этап.
- Abstract **не генерируется автоматически**, а берётся из поля `abstract`.
- Сайт и размещённые в публичном репозитории PDF доступны в интернете; размещайте только файлы, которые можно публиковать.

## Где находятся файлы

- `index.html` — главная страница
- `style.css` — внешний вид
- `graph.js` — дерево на D3.js, панель описания и кнопки PDF
- `data/articles.json` — дерево узлов, аннотации и ссылки на PDF
- `papers/` — четыре небольших **демонстрационных** PDF

Нет сервера, аккаунтов пользователей или платной базы данных. Библиотека D3 загружается через CDN, поэтому посетителю нужен доступ к интернету.
