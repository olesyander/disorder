# disorder map

Minimal dark interactive map of scientific publications. The catalog is maintained by the private `disorder-private` repository.

- White nodes: directories. Gold nodes: articles. Grey edges: hierarchy.
- Click a document to view its title, authors and abstract.
- Documents in `Articles/` or `Books/` are published in `papers/`, with **View publication** and **Download PDF** links.
- Documents in `Restricted Books/` are catalogued but their original files are not published.

**Public files are accessible to anyone, including through GitHub and direct URLs.** Only distribute copyrighted materials when you have permission. Published copies can remain in Git history even after removal.

GitHub Pages: `Settings → Pages → Deploy from a branch → main → /(root)`.
